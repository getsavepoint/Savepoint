# savepoint-mcp

Savepoint MCP proxy: blast-radius gate, 60-second staging airlock and deterministic LIFO revert for AI agent actions.

```bash
npx savepoint-mcp   # MCP over stdio; needs DATABASE_URL / REDIS_URL
```

Pair it with the typed client: `npm install savepoint-sdk`. Full docs: https://github.com/getsavepoint/savepoint
